# Zox Website Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a static Next.js marketing + docs site that matches `web-spec/` exactly in structure, tokens, and copy, with product facts taken only from `README.md` and `docs.md`.

**Architecture:** App Router site in `web/`. Server components by default. Client islands only for theme, copy, install tabs, FAQ, and the TUI mock. Docs are flat MDX files loaded with `gray-matter` + `next-mdx-remote/rsc`. Sidebar groups live in `web/lib/docs-nav.ts`, not in the filesystem.

**Tech Stack:** Next.js 15 App Router, React 19, TypeScript strict, Tailwind CSS v4 (`@theme` inline, no `tailwind.config`), `next/font` IBM Plex Mono, `next-themes` (`attribute="data-theme"`), `clsx` + `tailwind-merge`.

## Global Constraints

- Monospace only (IBM Plex Mono). No second font, no italic.
- Light canvas `#fdfcfc`, ink `#201d1d`. All colors via CSS variables in `web/app/globals.css`. No hard-coded hex in components except the TUI mock, which always uses the dark tokens (`#201d1d` / `#fdfcfc`) so it stays the dark panel in light mode.
- Radius 4px on buttons, inputs, code. TUI mock radius 0.
- Feature markers are ASCII `[+]`, `[-]`, `[x]`, `[*]`. No icon library.
- Routes: `/`, `/docs`, `/docs/[...slug]` only. No `/api`, no auth, no analytics, no search.
- `output: 'export'` in `next.config.ts`.
- Install commands must match the README. Tabs are **bun | bunx | pin**. There is no curl installer and the binary requires Bun, so do not document `curl` or `npm install` as a way to run Zox.
- Do not invent CLI flags, config keys, tool names, or model IDs. Quote `README.md` and `docs.md`.
- License line: MIT (confirmed in `packages/zox-code/package.json`).
- GitHub: `https://github.com/JayTheCoder77/Zox`.
- Do not commit. Leave the worktree dirty for review.
- Respect `prefers-reduced-motion`.
